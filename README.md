# ReadField

一套融合复杂故事文本与认知工具的读书会设计框架。

ReadField（阅读领域）创造了一个参与者能充分投入讨论，而设计者能系统传递思想的领域。基于某个完整故事的讨论保障了共读人的参与度，基于某套认知工具的设计让讨论中生长出来的洞见有了方向与体系。

## 首次实战

2026 年 7 月，知合 NEXUS 中山夏令营，7 天正课 + 2 天活动课。领读者牧远（王铭培）用田野调查作为认知工具，带一群共读人进入卡夫卡《城堡》。

- 主人公 K 被重塑为田野调查队派出的前哨
- 共读人作为后方调查主力，阅读、研究和评议前哨提供的材料
- 7 天完整教案 + 2 天"给 AI 安心眼子"盲评活动课
- 从课纲到实际交付的完整应变记录（见 `docs/应变参考.md`）

完整案例见 `samples/castle/`：课纲、每日教案源文件、K 的口吻文档、预热分享卡片，以及活动课的真实考题与共读人作品。

## 框架核心

三个通用角色：领读者、共读人、文本中的主人公。通过角色映射，让共读人与文本的关系发生结构性改变。

三个核心元素：导引、原文选段、对话触媒。每天的课程走三个环节：设定视角 → 进入文本 → 对话外延。

完整元框架定义和工作流见 `SKILL.md`。

## 快速开始

教育创新者可以和自己的 agent 协作，按以下 prompt 启动备课：

```
请用 ReadField 框架帮我备一门课程：

- 文本：[文本名称、基本信息]
- 认知工具：[方法论透镜，如田野调查、精神分析、制度分析]
- 共读人：[人数、背景]
- 总天数：[天数]
- 每天时长：[分钟]
- 角色映射：[三个角色的具体命名，如需要帮助可留空让 agent 建议]

请先从 Step 1 开始，跟我聊清楚课程骨架。
```
