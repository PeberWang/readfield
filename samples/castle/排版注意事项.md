# LaTeX 排版注意事项

本文档记录在 Castle 教案排版过程中遇到的陷阱和解决经验，供后续 Agent 在类似排版任务中参考。

---

## 1. 标点符号规范

### 1.1 中文上下文中必须使用全角标点
- 逗号：用 `，`（U+FF0C），不用 `,`
- 分号：用 `；`（U+FF1B），不用 `;`
- 冒号：用 `：`（U+FF1A），不用 `:`
- 问号：用 `？`（U+FF1F），不用 `?`
- 感叹号：用 `！`（U+FF01），不用 `!`
- 括号：用 `（）`（U+FF08 / U+FF09），不用 `()`
- 破折号：用 `——`（两个 U+2014 em dash），不用 `--`（LaTeX 会将 `--` 转成 en-dash `–`，不符合中文排版习惯）

### 1.2 引号
- 中文双引号用 `"`（U+201C）和 `"`（U+201D），不用 ASCII `"`
- 中文单引号用 `'`（U+2018）和 `'`（U+2019），不用 ASCII `'`
- ASCII 引号在 xelatex + ctex 中不会自动转换为中文引号，需要在源文件中就使用正确的 Unicode 字符
- **检测方法**：在中文文本上下文中（前后有 CJK 字符）出现的 ASCII 引号和标点，都应替换

### 1.3 LaTeX 转义序列的陷阱
- `\u201c`、`\u201d` 等 Python Unicode escape 被直接写入 tex 文件时，LaTeX 会将其逐字输出为 `\u201c` 而不是渲染为引号。必须转为真正的 Unicode 字符
- 任何以 `\u` 开头的字面文本都需要检查

## 2. 合并编译的陷阱

### 2.1 `\title{...\...}` 在正文中的行为差异
**这是导致合并版 Day 2+ 标题缩小靠左的根本原因。**

- 独立编译时，`\title{Day 2\\[0.3em]副标题}` 在 preamble 中定义，`\maketitle` 正确渲染为居中大字标题
- 合并版中，Day 2+ 的 `\title` 重新定义出现在 `\begin{document}` 之后的正文中。`\\[0.3em]` 在正文段落上下文中的解析方式不同，导致标题格式异常（缩小、靠左）
- **解决方案**：不要依赖 `\maketitle` 机制。改为手动 `\begin{center}{\LARGE\bfseries 标题}\end{center}` 渲染标题

### 2.2 `\maketitle` 在 article 类中可多次调用
- `article` 类的 `\maketitle` 内部使用 `\@title` 宏，`\title{...}` 会重新定义 `\@title`，所以理论上可以多次调用
- 但如果 `\title` 的新定义在正文中（而非 preamble），`\\` 的行为会不同

### 2.3 `\author{}` 和 `\date{}` 残留
- 合并时如果保留了 body 中的 `\maketitle`，其后续的 `\author{}` `\date{}` 空定义也会被保留，但无害
- 使用手动标题渲染时，需要从 body 中清理 `\maketitle` 及紧随的 `\vspace{}` 间距调整

### 2.4 `\fancyfoot` 需要 `fancyhdr` 包
- 原始文件使用了 `\fancyfoot[C]{\small\thepage}` 但没有加载 `\usepackage{fancyhdr}`，导致编译警告 "Undefined control sequence"
- 改用 article 默认的 `\pagestyle{plain}` 即可实现相同效果（页脚居中页码）

### 2.5 正则提取标题文本的陷阱
- `re.DOTALL` 标志下 `.+?` 会匹配换行符，可能导致提取 `\title{...}` 内容时越界，错误地包含了后续的 `\author` `\date` 命令
- 应使用括号配对法而非正则来提取 `\title{...}` 的内容

## 3. xelatex 编译

### 3.1 编译参数
- 必须用 `-interaction=nonstopmode` 避免 halting on error
- MiKTeX 管理员检查警告 "So far, no MiKTeX administrator has checked for updates" 可忽略

### 3.2 合并版必须编译两遍
- 第一遍生成 `.aux` 和 `.toc` 文件
- 第二遍读取 `.toc` 生成正确页码的目录

### 3.3 tocloft 的目录标题
- 使用 `\renewcommand{\contentsname}{目录}` 确保目录页标题为中文
- ctex 默认 `\contentsname` 为"目录"，但 tocloft 可能覆盖——显式设置更安全

## 4. 验证检查清单

合并前逐天检查：
1. [ ] 所有中文上下文中的标点为全角（逗号、分号、冒号、问号、感叹号、括号）
2. [ ] 所有引号为 Unicode 中文引号 `""`，非 ASCII `"`
3. [ ] 破折号用 `——`（两个 em dash），非 `--`
4. [ ] 无 `\u201c` `\u201d` 等字面转义序列
5. [ ] 无不必要的 `\usepackage{fancyhdr}`（如用 `\pagestyle{plain}` 则不需要）

合并后检查：
1. [ ] 封面正确（可选）
2. [ ] 目录标题为"目录"，页码正确
3. [ ] Day 1-7 标题居中、`\LARGE\bfseries`、与独立编译版一致
4. [ ] Day 4（补充材料）标题只显示"补充材料"
5. [ ] 各天正文中无 `\author{}` `\date{}` 干扰
6. [ ] 引用注释格式统一（如去掉"城堡"，仅保留"第X章"）
7. [ ] xelatex 两遍编译零错误
