# insight-card — 预热分享卡片

课程正式开始之前，领读者可以做一系列轻量分享，为共读人预热话题和氛围。预热分享的载体是信息密度适中的单页卡片，适合直接在社群（如微信群）中转发阅读，不需要额外解释。

## 设计原则

- **不是课程预告**：卡片不与课程具体文本挂钩，而是与课程主题相关的社会观察和讨论素材。预热的是问题意识，不是内容剧透。
- **一张卡片一个话题**：标题、为什么分享（1-2 句）、思考题（1-2 个）、延伸阅读推荐、来源，五要素齐全即可，不贪多。
- **转发友好**：单页 PNG，2x 高清，发到群里就能读，读者不需要任何背景知识。

> *例："重返城堡"课程预热期间，每天分享一张卡片，话题包括"抱怨作为一种政治行为""被外包的大政方针""城与村，中心与边缘"等，与课程主题（基层治理、官僚组织、空间政治）相关但不直接剧透。成品见 `samples/castle/daily-share/`。*

## 生成

```
python insight_card.py
```

脚本按调用参数渲染 HTML 并用 playwright 截图输出 PNG。依赖：`pip install playwright && playwright install chromium`。

卡片内容（标题、为什么分享、思考题、延伸阅读、来源、标签）由领读者与 agent 讨论确定后作为参数传入。视觉语言固定（衬线字体、卡片式排版），内容逐日更换。
