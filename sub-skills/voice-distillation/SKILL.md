# voice-distillation — 口吻蒸馏

ReadField 的导引以主人公口吻写就。要让 agent 写出"像主人公"的文本，不能只靠一句"请模仿 K 的文风"，而需要两份基础文档：

- **Voice 文档（口吻蒸馏）**：从原文本中提炼主人公的说话风格和思维特征——语调与情绪、认知方式、语言习惯、世界观与信念、边界（不会做什么）、写作指南和采样片段。这份文档让 agent 能够"成为"主人公。
- **Role 文档（角色定位）**：定义主人公在课程中的角色、职责和行事方式——在三角关系中的位置、写信时的姿态（对谁说、怎么说）、在不同天中的角色微调、明确不做的事。这份文档让 agent 理解主人公在课程结构中的功能。

两份文档互补：voice 定义"主人公怎么说话"，role 定义"主人公以什么身份在做什么"。生成导引时必须同时参考两份文档。

> *例：castle 课程中，`samples/castle/voice-k.md` 从《城堡》全文中蒸馏了 K 的紧绷冷静、分析者认知、短句交锋风格等特征；`samples/castle/role-k.md` 定义 K 为田野调查队的前哨，写信给同志而非上级，不布置任务而是分享所见所闻。*

## 蒸馏方法

完整的蒸馏流程（四个维度、五个步骤、输出格式）见 `voice-distillation-strategy.md`。要点：

1. 从语料中采样 5-10 个代表性片段，覆盖不同情境
2. 沿语调与情绪、认知方式、语言习惯、世界观与信念四个维度提取特征，**每条特征必须附原文证据**
3. 交叉验证四个维度是否自洽
4. 标注边界：角色不会说什么、不会怎么说话。负面空间和正面空间同样重要
5. 输出结构化风格文档，含写作指南和采样片段

蒸馏出的 Voice 文档是独立资产：之后生成新文本只需读取它，无需重新读取原始语料。
