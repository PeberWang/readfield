# blindlab — 盲评活动课

活动课是 ReadField 主课之外平行开展的实践环节。核心机制是**盲评竞赛**：共读人把自己对认知工具的理解外化为一套指导 AI 行动的指令（Skill），让 AI 带着这些指令去应对读书会正在探索的一类情境；然后在不知道作者是谁的情况下，评价不同 Skill 的表现，投票打分得到排名。

理解不是听来的，是对比出来的。好的活动课让共读人在富有趣味的竞争中，自发探索主课试图传达的深刻问题。教学设计原理见 `设计.md`。

## 一堂活动课的组成

- **考题（场景）**：领读者围绕课程主题命制的情境题，每题在关键处留白，AI 的回应填在留白处。castle 课程的实例见 `samples/castle/scenarios/`。
- **心法（Skill）**：共读人小组在 AI 协作下设计的"人格与策略说明"。简单心法是一份 markdown；工作流型 skill 是含 `SKILL.md` 的文件夹，可带 playbook、模板等多步工作流资源。
- **启动包**：发给共读人的开发环境，含游戏说明书、输出契约、工程指南等，见 `starter-pack/`。启动包是课程实例的一部分，开新课需按自己课程改写。
- **盲评**：所有回应抹去作者信息、以盲码编号投屏展示，全员按多维度打分，最后揭晓排名与作者。

## 现场流程（装置已自动化）

装置名 blindlab（盲评实验台），目标是在 1 小时的活动课现场零手工操作跑完。命令详表见 `README.md`，领读人跑会前照着做的清单见 `现场操作手册.md`。

```
收 skill（skill import）→ 生成回应（generate / delegate）→ 盲评投屏（present responses）
→ 建评分表（ballot create）→ 统计排名（tally / present ranking）→ 对比讨论（present compare）
→ 揭晓（reveal）
```

工作流型 skill 由 OpenClaw 子进程作为执行体跑完，编排规程见 `RUNBOOK-openclaw.md`。

## 如何写一份好的启动包

启动包是共读人在聊天 AI 里的开发环境。它的设计目标只有一条：**一个只有一部手机的人，把包丢进聊天框，就能走完全流程**。castle 实践的启动包在 `starter-pack/`，以下要点来自那次实战。

**解剖：五份文档，各司其职**

| 文档 | 职责 |
|------|------|
| 游戏说明书 | 为什么玩、怎么赢。先搞懂规则再动手 |
| 输出契约 | 硬技术规格。成品能不能被管道执行，全看这一条 |
| Skill 工程指南 | 什么是好 skill：结构、分区、编排模式、常见败笔 |
| 领域提示单 | 供 AI 引导时取用的视角素材。课程主题的灵魂在这里 |
| 协作流程 | 和聊天 AI 协作的分阶段剧本，含成品交付方式 |

外加两份材料：`示例-*/` 一个完整参考实现，`骨架模板/` 一个带注释的空架子。示例是给共读人拆的，不是给抄的——盲评对照之下，抄来的骨架没有灵魂，必现形。

**设计要点**

1. **聊天即开发环境。** 共读人没有文件系统、没有工具链，包必须自包含全部信息；成品交付靠输出契约（`===FILE:===` 分块或云电脑打包 zip），不依赖任何本地软件。
2. **契约与教学分离。** 硬规格单独成文，管道按它校验；工程方法与领域视角另立文档。混在一起，共读人和 AI 都会把规格当建议。
3. **写明开场白。** 包里直接给出第一句话（"请通读全部文件，按协作流程带我们走"），降低冷启动门槛。
4. **交付要有兜底。** zip 首选，单文件 txt 兜底；并要求转发文件本身而不是下载链接——链接会过期。
5. **开新课时**：说明书、契约、工程指南、协作流程的骨架可沿用；领域提示单必须按课程的认知工具重写，情境说明与示例换成自己课程的素材。

## 开新课

课程实例（轮次、评分维度、分值、提示词）都在 `course.yaml`，复用者改这个文件、换场景与启动包即可，不动代码。

## 文件地图

| 路径 | 用途 |
|------|------|
| `设计.md` | 活动课的教学设计理念（为什么盲评、为什么多维评分） |
| `README.md` | 装置命令详表、数据格式、架构、故障预案 |
| `现场操作手册.md` | 领读人跑会当天的操作清单 |
| `RUNBOOK-openclaw.md` | 工作流型 skill 的子进程编排规程 |
| `course.yaml` | 课程实例配置 |
| `starter-pack/` | 共读人的开发环境（随课程改写） |
| `examples/skills/` | 四份示例心法（三份简单心法 + 一份工作流型 skill） |
| `tools/` | 启动包打包、导入测试、活动海报生成 |
