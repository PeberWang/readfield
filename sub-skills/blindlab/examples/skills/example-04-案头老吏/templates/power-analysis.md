# 权力结构分析模板

对场景逐项回答以下六个问题。每一项必须引用场景中的具体细节作为依据，没有依据就写「不明」——「不明」本身就是重要信息。

## 1. 对方的权力从哪来

对方声称的授权是什么（谁派的、什么名义）？这个授权有没有被验证过？是正式程序还是私人意志的延伸？

## 2. 我方有什么把柄在对方手里

对方已经掌握了我方什么信息？这次对话可能新增什么把柄？最坏情况下这些材料会流到谁手里？

## 3. 信息分布

我方知道而对方不知道的是什么？对方知道而我方不知道的是什么？哪些信息是双方都不知道但假装知道的？

## 4. 第三方在场

现场有没有旁观者？他们是谁的人？这次对话有多少成分是做给旁观者看的？

## 5. 可置信承诺的空间

在这个权力结构下，我方说什么话是可信的？说什么话对方根本不会信？哪些承诺一旦出口就收不回来？

## 6. 退出成本

如果我方现在拒绝、拖延或离场，代价是什么？这个代价由谁执行、通过什么程序执行？有没有程序空子可钻？

## 结论

基于以上六项，这个场景对我方的核心威胁是什么？一句话说清。
