# 心眼子启动包

这是「给 AI 安心眼子」工作坊的小组启动包。你们小组的任务是设计一个 skill，替你们上场参加三情境盲评。这个包里装着完成这个任务所需的全部信息，以及一套和 AI 协作的工作方法。

## 两个目的

一，干中学。skill 是 AI 时代一种新的工程形态，它有自己的结构、功能分区和编排方式。你们不需要提前懂这些，这个包里的材料加上聊天的过程，会逼你们把它搞明白。

二，借 skill 设计深化组织理解。你们的 skill 要在官僚组织的迷宫里活下来，靠的是你们对权力、程序、人情、信息的真实理解。设计的过程就是把这种理解逼出来的过程。

## 怎么用

一，把这个包丢进 Kimi 网页端的聊天框。如果你拿到的是单文件版（心眼子启动包.txt），直接上传即可——它以 ===PACK-FILE:=== 分块包含全部文件，AI 会按路径复原目录结构。如果你拿到的是 zip，先解压，把全部文件逐个上传或全选粘贴（Kimi 聊天不收 zip）。

二，发这句话作为开场：

> 请先通读这个启动包的全部文件（如为 ===PACK-FILE:=== 分块格式，按路径复原目录结构理解），然后严格按《05-协作流程》带我们小组走。最后交付成品时，需要你在自己的云电脑（代码运行环境）里把 skill 文件夹建出来并打包成 zip 给我们下载——这是在你的运行环境里生成文件，不是操作我们的设备。

三，跟着流程聊。聊透了，AI 会动手把你们的 skill 建出来，最后按《02-输出契约》的交付方式交出成品。

四，把 AI 给出的 zip 文件下载下来，转发给领读人——转发文件本身，不要只转发下载链接，链接会过期。如果平台实在不能生成文件，就把它吐出的那条成品消息原样转发。发到领读人手里，就是提交。

## 包内清单

- 《01-游戏说明书》活动规则、情境结构、盲评方式。先搞懂游戏规则再动手
- 《02-输出契约》成品的硬性技术规格。你们的 skill 能不能被实验管道执行，全看这一条
- 《03-Skill工程指南》什么是好 skill。结构、分区、编排模式、常见败笔
- 《04-组织理解提示单》一组供 AI 引导时取用的视角。你们的组织理解是 skill 的灵魂
- 《05-协作流程》和聊天 AI 协作的六阶段剧本，含成品交付的方式
- `示例-案头老吏/` 一个完整的参考实现
- `骨架模板/` 一个带注释的空架子，AI 建成品时参照它

## 一条提醒

示例是给你们拆的，不是给你们抄的。评分时上场的是你们自己长出来的组织理解，抄来的骨架没有灵魂，三情境对照之下必现形。
