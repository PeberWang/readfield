# 心眼子活动课 · 现场操作手册（领读人用）

本课配置：**单轮 day1**，三道考题（castle-01 一封危险的公函 / real-01 一份说不清的督查通知 / real-05 县委定指标之后），全部 skill 为工作流型（OpenClaw 子进程执行）。
所有命令在本目录（`sub-skills/blindlab`）下执行。终端中文若显示乱码不影响实际数据，可用 `chcp 65001` 改善。

---

## 第一阶段：实测（课前自测，测试 skill + 基准）

```bash
# 1. 确认输入：应见 2 个工作流 skill、3 道考题
python blindlab.py skills
python blindlab.py scenarios --round day1

# 2. 建盲码与回应容器（工作流型不走 API，显示"新增 0 条"属正常）
python blindlab.py generate --round day1

# 3. 出子进程任务清单（应见 6 条任务 = 2 skill × 3 场景）
python blindlab.py delegate plan --round day1
```

**→ 交接小劳**：让它读 `RUNBOOK-openclaw.md`，按 `data/results/agent_plan_day1.json` 每个 skill spawn 一个子进程。跑完后继续：

```bash
# 4. 回收子进程产出（[OK]=已并入；!!=逐条问题，修好对应文件重跑本命令即可）
python blindlab.py delegate collect --round day1

# 5. 投屏页（方向键翻页，长文自动缩字）
python blindlab.py present responses --round day1 --open

# 6. 走完一遍后清场，为正式课复位
python blindlab.py reset --round day1
```

实测要练的就是 2→6 这条链，重点看：小劳 spawn 是否顺、collect 是否 6 条全 [OK]、投屏页三道题渲染是否满意。

## 第二阶段：上课当天（正式跑）

### 课前（收 skill 时）

1. 各组 zip 收进 `../../samples/castle/skills/`（开新课则收进本课程对应目录）
2. 逐个导入（key 缺省取 zip 内文件夹名；重名时加 `--key 新名`）：

```bash
python blindlab.py skill import "../../samples/castle/skills/某组.zip"
python blindlab.py skills    # 确认全部识别为[工作流]
```

3. 测试 skill/基准若要上场就留在 `data/skills/`，不上场就移到 `data/skills/` 之外的任何地方
4. 确认清场状态：`python blindlab.py reset --round day1`（显示"本来就没有状态文件"最好）

### 课中（投影旁照此操作）

```bash
python blindlab.py generate --round day1        # 建盲码
python blindlab.py delegate plan --round day1   # 出清单
# → 小劳按 RUNBOOK-openclaw.md spawn 子进程（N 个 skill = N 个子进程，各跑 3 题）
python blindlab.py delegate collect --round day1 # 回收，确认全部 [OK]
python blindlab.py present responses --round day1 --open  # 投屏盲评
```

观众看回应时建评分表：

```bash
python blindlab.py ballot create --round day1
# 打印链接 → 网页打开 → 基于该表建「问卷」视图 → 生成二维码投屏
```

评分结束：

```bash
python blindlab.py tally --round day1                       # 拉票看排名
python blindlab.py present ranking --round day1 --open      # 排名投屏
python blindlab.py present compare --round day1 --left 01 --right 02 --open  # 任意两码对比（讨论用，可多次）
python blindlab.py reveal --round day1                      # 揭晓盲码与作者
```

## 故障速查

| 症状 | 处置 |
|------|------|
| collect 有 `!!` 行 | 按提示修对应 JSON（缺字段/坏 JSON/盲码陌生），重跑 collect，已并入的不受影响。「JSON 解析失败」多半是回应里英文双引号没转义 |
| 某子进程要重跑 | 删它 `data/results/agentic/day1/...` 下的输出 JSON → 重跑 plan 重新入单 → 小劳重跑 → collect |
| 飞书频率限制（99991400） | 等几十秒自动穿过，别狂点重跑 |
| 投屏页字太小/溢出 | 已内置自动缩字（下限 1.5vh）；刷新页面重排 |
| 想整轮重来 | `reset --round day1`（飞书表要删加 `--purge-feishu`） |

## 现场禁忌

- 一轮之内不换模型、不改 `agent_plan_day1.json` 里的路径
- `reveal` 之前不打开 `data/results/blind_day1.json`
- 不动 `data/results/` 下手改 JSON（要改先备份）
